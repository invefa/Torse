# 客户端

包名：`torse-client`。当前提供三种模式，共用同一场景、网格与管线：`--capture`离屏渲染一帧PNG；`--window`打开交互窗口，连续渲染、分区流式装载、选中放置与破坏方块，并提供飞行与行走两种相机，行走移动经A4事务提交；`--connect`在窗口模式上连接独立服务端，镜像A7授权投影并把编辑作为请求发给服务端。

## 运行

```sh
# 离屏单帧
cargo run -p torse-client -- --capture out.png --width 960 --height 720 --radius 2
# 交互窗口
cargo run -p torse-client -- --window --radius 4
# 自动飞行取证，呈现N帧后退出并可存最后一帧；飞行中每24帧交替破坏/放置准星目标
cargo run --release -p torse-client -- --window --autoplay --frames 4000 --radius 4
# 行走模式取证：自动前进，遇台阶自动跳跃
cargo run --release -p torse-client -- --window --walk --autoplay --frames 2400 --radius 3
# 联网取证：先起服务端（新世界铺地面），客户端连接并镜像
torse-server <dir> --listen 127.0.0.1:7799 --fill
cargo run -p torse-client -- --window --connect 127.0.0.1:7799 --autoplay --frames 300
# 联机编辑：服务端加--editors后，点击与自动演示经服务端提交并回投批次
torse-server <dir> --listen 127.0.0.1:7801 --fill --editors
```

| 参数 | 含义 |
|---|---|
| `--capture` | 离屏模式，输出PNG路径 |
| `--window` | 窗口模式，未指定时按离屏处理 |
| `--width`、`--height` | 图像或初始窗口尺寸，默认960x540 |
| `--radius` | 分区半径，离屏默认2，窗口默认4 |
| `--view` | 离屏相机：`overview`或`player`，默认俯视全景 |
| `--frames` | 窗口模式呈现指定帧数后自动退出，供取证 |
| `--screenshot` | 窗口模式退出前保存最后一帧PNG |
| `--autoplay` | 窗口模式自动前向飞行并演示破坏/放置，供取证 |
| `--walk` | 以行走模式启动，自动前进时遇台阶自动跳跃 |
| `--connect` | 连接独立服务端：镜像授权投影渲染实体，点击与自动演示作为请求发送；访客收到拒绝，服务端`--editors`策略下提交生效并经批次回投 |
| `--probe-outside` | 连接后发送一个目标在批准scope外的请求，验收越界拒绝 |

流式装载每帧限量生成（近列优先），编辑只重传受影响分区的缓冲，帧时指标在退出汇总中。飞行模式：WASD移动，空格与Shift升降。行走模式（F5切换，或`--walk`启动）：WASD行走，空格跳跃，移动经A4事务提交、重力与碰撞由权威解析。两种模式下按住鼠标左键或右键拖动转向，滚轮调节速度；短按左键破坏准星方块，短按右键沿选中面放置，数字键1到3切换石头、玻璃半砖与植物；F12截图到`torse-shot-N.png`，Esc或关闭窗口退出。准星处绘制选中框线框。

需要可用的图形后端。本机实测走Vulkan，集显即可。CI不执行渲染，只做编译检查。

## UI

窗口默认绘制素材化HUD：准星、三格快捷栏、当前方块与连接状态。1到3切换方块，Esc打开或关闭菜单，E打开明确标注示例数据的机器面板预览；菜单提供返回、预览和退出。面板打开时清空移动、拖动和编辑输入，网络接收继续运行。本地行走暂不推进，联网世界不因菜单暂停。关闭窗口仍可直接退出，F12在面板中也可截图。

```sh
cargo run -p torse-client -- --window
cargo run -p torse-client -- --window --ui-preview machine
cargo run -p torse-client -- --capture ui.png --width 960 --height 540 --ui-preview machine
```

`--ui-preview`接受hud、pause和machine，两种渲染路径共用UI管线。界面按窗口空间自动选择1到4倍整数缩放，最小窗口640x360；PNG在编译时嵌入，窗口和按钮采用九宫格拉伸。中文与英文文案位于games/base/assets/locales，字体从操作系统读取，不随程序打包；可用TORSE_UI_FONT指定TTF、OTF或TTC。自动字体搜索依次覆盖Windows中文字体、Linux的Noto CJK、macOS中文字体和Linux的DejaVu；缺少中文字形时使用英文资源，未找到可用字体则返回明确错误。

机器面板本轮只验证布局与素材，不读写真实机器或库存，不声明B10完成。授权UI状态、动作绑定、断线重建与双客户端机器验收继续后续接入。截图及验证见[UI基础](../../benchmarks/M1-ui.md)。

## 代码组成

| 文件 | 职责 |
|---|---|
| [scene.rs](src/scene.rs) | 装配`WorldAuthority`与动作服务、注入丘陵生成器、按半径装载并建网格、提交放置与破坏事务 |
| [renderer.rs](src/renderer.rs) | `GpuContext`地形与线框双管线、离屏目标及PNG写出的公共路径 |
| [window.rs](src/window.rs) | winit窗口、surface配置、帧循环、流式装载与动作调度、窗口截图 |
| [camera.rs](src/camera.rs) | 透视与视图矩阵；`FlyCamera`按偏航俯仰积分飞行 |
| [input.rs](src/input.rs) | 按键、鼠标与滚轮的帧级聚合，区分点击与拖动 |
| [pick.rs](src/pick.rs) | 体素DDA拾取射线，返回目标格与进入面 |
| [main.rs](src/main.rs) | 参数解析与两种模式的入口 |
| [ui](src/ui/mod.rs) | 素材、文字、HUD、模态输入与机器面板预览 |

顶点为位置、法线、颜色各三浮点，共36字节，按材质映射到一个扁平颜色，光照由法线与固定方向光决定。窗口surface格式由适配器决定（本机为BGRA），管线颜色目标按实际格式创建，截图读回时转换成RGBA。

点击先由拾取射线解析目标格与面，放置沿面偏移一格；每次编辑经`ActionService::plan`完成权限、版本与前置条件校验，再由`WorldAuthority::commit`提交，客户端不绕过动作服务直接写世界。

行走模式在场景内维护玩家实体与客户端物理（步速、重力、起跳），每20分之一秒把位移组装成移动事务提交，碰撞在权威准备阶段解析，相机读回最终位置跟随；出生点按地表高度换算，嵌入地形的出生会因移动前置校验冻结，切回飞行再切换即可恢复。

联网模式（`--connect`）：握手兼容信息与服务端演示装配一致（m0夹具、方块动作与库存模块共同注册）；基线经符号表解析回本地注册表并装载分区与实体，实体以色块入画；增量批次重装对应分区并使网格缓存失效。点击与自动演示发送类型化请求，返回的准入与结果显示在标题与汇总。访客策略下全部拒绝；服务端`--editors`策略按订阅分区授权，提交经批次回投并更新画面，本地始终不直接提交。订阅范围固定为演示scope，行走可在镜像地形上本地预测。

## 边界

- 联网模式只读：授权编辑等待A侧范围授权扩展；订阅范围固定，无随玩家移动的订阅变更。
- 实体以色块入画：玩家由相机表现并排除渲染，正式实体表现待后续；行走实体不持久化。
- 行走无自动上台阶、斜坡与水；出生嵌入地形时冻结，需切回飞行再切换。
- 放置不消耗库存、破坏不产生掉落；命令解析与网络输入适配待后续。
- 拾取按完整立方体处理非空格；只装载`y = 0`分区层，编辑与拾取限于此层。
- 无纹理、阴影与透明排序；着色器与离屏路径相同。
- 方块修改经动作服务事务提交，行走经移动事务提交，客户端不直接写世界。
